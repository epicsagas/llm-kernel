실증 비교분석 · embedding & graph recall

llm-kernel 임베딩·그래프, 타 시스템 대비 성능 위치

환경 Apple M2 / 16GB / Metal 측정일 2026-08-10 범위 임베딩 6 · 그래프 4 시스템

임베딩 — 단일 embed 6.9ms (전 시스템 최고). candle-Metal(Qwen3)은 CPU 대비 2.2× 가속 확인. 단, 배치 throughput은 MLX에 2.4× 열세(ort에 Metal EP 없음).

그래프 recall — hint 시 19–45µs, 전체 회귀 0.93–1.12ms. Mem0(33ms)·Zep(155–162ms) 대비 30–100× 빠름. 단, 결정론적 회귀라 정확도 벤치는 별과제.

트레이드오프 — llm-kernel은 LLM 0 · 외부 DB 0 · 오프라인. Zep/Mem0/Letta는 LLM-in-loop + 서버 + 그래프 DB로 정확도·기능 우위, 단 비용·지연·의존 증가.

Metal이 CPU 대비 2.2–2.3× 일관적 가속. 큰 모델일수록 GPU 이득 큼.

  • 단일 embed는 llm-kernel(6.9ms)이 최고 — ONNX JIT가 단일 호출 오버헤드에서 유리.
  • 배치는 mlx(996 t/s)가 압도. llm-kernel(409)은 2.4× 느림 — ort에 Apple Metal EP 없음. bge-small 가속은 embedding-fastembed-coreml 활성화가 유일 경로 (후속 최우선).
  • ollama는 HTTP/JSON 오버헤드로 배치 비효율(42 t/s). 단일 서비스/모델 교체 용이성은 장점.
  • 환경 결함 발견: 기존 torchaudio 2.9.1이 torch 2.11과 네이티브 lib 충돌 → sentence-transformers import 파괴. 제거로 복구.

  • llm-kernel이 Mem0 대비 ~34×(search), Zep 대비 ~100× 빠름 — 단, 결정론적 회귀라 LLM-rerank 정확도는 비교 불가.
  • hint 있으면 FTS5가 후보 축소 → PageRank 부스트 대상 감소 → no_hint 대비 20–50× 단축.
  • Zep은 bi-temporal + cross-encoder rerank로 정확도 94.7% 달성, 단 LLM 비용·지연·프라이버시 의존.
  • llm-kernel 정확도 벤치 부재가 핵심 갭 — 지연 우위는 증명, 정확도 위치는 미지수.

llm-kernel — "AI 네이티브 기반 라이브러리". 도메인 타입(provider/tokens/embedding)은 외부 의존 0, 기능별 feature gate, hexagonal. 회귀를 LLM 없이 결정론적 수식(PageRank 중심성 + FTS + 시간 감쇠). 임베디드/오프라인/저지연/비용 민감 + 프라이버시 강점.

Zep/Mem0/Letta — "에이전트 메모리 서비스". LLM을 회귀 루프에 투입, 정확도·맥락 이해 우위. bi-temporal(Zep), 자가 편집(Letta) 고기능. 단 비용·지연·인프라(그래프 DB+서버) 의존.

서로 다른 문제. 경쟁이 아닌 목적 차등 — llm-kernel 위에 Zep형 LLM-rerank를 얹는 하이브리드가 유효 전략.

04 한계 · 측정 갭

  1. Letta / Graphiti 로컬 미측정 — 그래프 Agent doc-research 단계에서 yield. 아키텍처는 문서 추정, 수치 갭.
  2. llm-kernel recall 정확도 벤치 부재 — 지연만 측정. LoCoMo/LongMemEval 표준 벤치에서 정확도 미측정 → 최우선 후속.
  3. TEI 로컬 미측정 — podman/소스 빌드 시간 초과. A10 수치(450+)만 인용. M2 TEI 갭.
  4. embedding-fastembed-coreml 미측정 — bge-small MLX 대항 경로. 후속 가치 최상.
  5. MTEB 정확도 인용 — 리더보드 공개 수치(비실측).
  6. 열 스로틀 미모니터링 — M2 Air 패시브. 서스테인드 로드 시 변동 가능.

05 결론 및 권고

llm-kernel 강점

  • 단일 임베딩 최고 속도 (6.9ms)
  • candle-Metal 2.2× 가속 확증
  • 그래프 recall 30–100× 빠름
  • 0 외부 의존 · 오프라인 · 프라이버시

개선 우선순위

  • coreml EP 벤치 → MLX 대항
  • recall 정확도 벤치 도입 (LoCoMo)
  • TEI Metal 로컬 벤치
  • Nomic MoE candle 검증

타 시스템 대비 위치: Zep/Mem0/Letta는 LLM 강화 정확도·고기능 우위(장기 메모리) — 단 비용·지연·인프라 의존. llm-kernel은 결정론·저지연·LLM-free. 보완 관계 — llm-kernel을 회귀 기저로, Zep형 LLM-rerark를 상위 레이어로 얹는 하이브리드가 양쪽 강점 결합.
